# Pantallas de referencia

`pantallas.html` son las pantallas de referencia que dio la cátedra para el 2º parcial. Abrilo en el navegador:
es un lienzo que se arrastra y se acerca, con cada pantalla y el requerimiento que cubre (RF-V1, RF-P6, RF-U5…).

Grupos: Acceso, Inicio, Ventas, Productos, Clientes, Usuarios, Vendedor (lo que ve ese rol) y Teléfono (390 px).

**Importante (sección 8 del enunciado):** son referencia de **contenido y flujos**, no de diseño.
La interfaz se arma con shadcn/ui y Tailwind con la identidad visual propia del proyecto
(ver [`../04-pantallas-y-diseno.md`](../04-pantallas-y-diseno.md)); no se copia el formato de estas pantallas.
